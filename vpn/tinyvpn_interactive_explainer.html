Explore The Stack

01Handshake Static identity keys authenticate peers. Ephemeral keys rotate session secrecy forward.
02Transport Authenticated headers carry tunnel ids, sequence numbers, and fragmentation metadata.
03Multi-Hop Each relay decrypts one route layer and forwards the next encrypted wire packet.
04Observability FastAPI exposes snapshots and a WebSocket stream for peer health, loss, RTT, and errors.
05Windows Ops Wintun plus automatic routes, DNS changes, cleanup, and roaming-friendly endpoint updates.

Client

Initiates a Noise-style handshake, installs a tunnel id, and encrypts raw IP packets from the TUN interface.

Server / Relay

Authenticates the initiator, derives directional keys, handles roaming, and can relay an inner hop without decrypting it.

Noise-style auth

The initiator sends an ephemeral key and an encrypted static identity payload instead of a pre-shared secret blob.

Header as AAD

Tunnel id, sequence number, and fragment metadata are authenticated by AES-GCM and cannot be altered safely.

Debug without hot-path cost

Packet inspection stays outside the transport fast path and only runs when debug mode is enabled.
